¿Es MVC o MTV?

Django utiliza formalmente el patrón MTV (Model - Template - View). Al desarrollar una API REST que no renderiza plantillas HTML en el servidor (sino que alimenta una SPA en Angular), la estructura se adapta: el Model gestiona datos, la View atiende las peticiones HTTP y el Serializer sustituye al Template para transformar la representación de los datos.

Herederos-Alzate — Sistema de Inventario

Maneja arquitectura por capas en backend (Django + PostgreSQL) junto con una organización modular por funcionalidades en el frontend Angular:

Estructura Modular Angular (PPI-master/src/app/) 
app/
├── compartido/
│   └── disenos/                # Componentes y estilos comunes
├── nucleo/
│   ├── guardias/               # Control de rutas y seguridad
│   └── servicios/              # auth.service.ts y servicios singleton
└── paginas/
    ├── funcionalidades/        # Módulos encapsulados por dominio
    │   ├── autenticacion/
    │   ├── empleados/
    │   ├── inventario/
    │   └── prove/
    ├── home/
    └── perfil/

Esta estructura separa adecuadamente los elementos compartidos de los servicios centrales con inyección de dependencias, facilitando la escalabilidad del sistema.
