# Mi Portafolio

Proyecto web desarrollado con [Angular](https://angular.dev/).

---

## 🚀 Cómo empezar / Clonar y ejecutar

### 1. Clonar el repositorio
```bash
git clone https://github.com/BonzJJ11/MiPortafolio.git
cd MiPortafolio
```

### 2. Instalar dependencias
Entra en la carpeta del proyecto Angular e instala las dependencias:
```bash
cd portafolio
npm install
```

### 3. Ejecutar en desarrollo
Inicia el servidor de desarrollo local:
```bash
npm start
```
O con Angular CLI directamente:
```bash
ng serve
```
Abre tu navegador en `http://localhost:4200/`.

- **Framework:** Angular 21
